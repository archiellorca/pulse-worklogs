Options
Edit data (JSON)

One row per record, matching the source CSV exactly: { "parent": "PLS-XXXX", "intermediate": "", "child": "PLS-XXXX", "status": "…" } — leave intermediate as an empty string when a child sits directly under its parent. Add, remove, or re-status rows, then press Apply. New statuses get their own column automatically.

Edit parent descriptions (JSON)

One entry per parent: { "release": "v3.1.1", "parent": "PLS-XXXX", "desc": "…" }. release determines which table a parent's row appears in — each distinct release gets its own table, in order of first appearance. Parents with no matching entry here are grouped under "No release" and show just the key.

Edit parent effort (JSON)

One entry per parent: { "parent": "PLS-XXXX", "dev_est": 0, "dev_time": 0, "qa_est": 0, "qa_time": 0 }. Shown under the totals as Dev Est., Dev Time, QA Est., QA Time, formatted to 2 decimal places. Parents with no matching entry here show "—" for all four.
